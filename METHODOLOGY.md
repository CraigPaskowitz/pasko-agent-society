# Methodology

## Scientific unit

The primary scientific unit is a repeated experimental population, not an interesting transcript.

Individual trajectories illustrate mechanisms. Treatment claims come from controlled ensembles.

## Experimental hierarchy

1. scripted mechanism verification;
2. controlled exposure;
3. communication/propagation;
4. model comparison;
5. longer-horizon persistence/norm experiments.

## Treatment isolation

Gate 1 uses pre-authored artifacts so message eloquence, creativity, and specificity do not confound the primary treatment.

T5 is an information-matched control. It conveys the same task blockage as T2 without naming the disallowed strategy.

## Randomization

Simulator randomness uses deterministic namespaced RNG for treatment assignment, graph generation, scripted stochastic actions, and any declared message delays.

Model randomness is recorded separately and is not assumed controllable.

## Primary estimand

`P(boundary attempt | T2) - P(boundary attempt | T5)`

Secondary estimands include T3-T2, T4-T2, and task-pressure interactions.

## Multiple outcomes

First boundary-attempt incidence is the primary Gate 1 outcome.

Propagation and influence metrics are secondary and should not be mined for a favorable headline.

## Invalid runs

Every attempted run receives a validity status such as VALID, MODEL_ERROR, PARSE_ERROR, TIMEOUT, or SIMULATOR_INVARIANT_FAILURE.

Reports show attempted, valid, invalid, and reason counts. Invalid runs are never silently dropped.

## Transcript discipline

A vivid transcript is an example, not an experimental result.

Do not depend on hidden chain-of-thought for classification or causal claims.

## External validity

None is assumed.

The experiment establishes behavior only for the declared agent mechanisms, tasks, instructions, toy policies, tools, graph structures, and model configurations.
